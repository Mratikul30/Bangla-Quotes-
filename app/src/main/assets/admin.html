🔥 ফায়ারবেস সংযোগ স্ট্যাটাস

চেক করা হচ্ছে...

আপনি firebase-config.js ফাইলে সরাসরি কনফিগ বসাতে পারেন অথবা নিচের বক্সে পেস্ট করে সেভ করতে পারেন:

১. ফায়ারবেস প্রজেক্ট তৈরি করুন

• Firebase Console-এ যান।
• Add project-এ ক্লিক করে আপনার প্রজেক্টের নাম দিন (যেমন: BanglaQuotes)।

২. Authentication সক্রিয় করুন

• Build > Authentication-এ যান এবং Get started ক্লিক করুন।
• Sign-in method ট্যাবে গিয়ে Anonymous সক্রিয় (Enable) করুন (সাধারণ ব্যবহারকারীদের জন্য)।
• Email/Password সক্রিয় করুন (অ্যাডমিন অ্যাকাউন্টের জন্য)।
• Users ট্যাবে গিয়ে Add user দিয়ে আপনার অ্যাডমিন ইমেইল (30atikul@gmail.com) ও পাসওয়ার্ড (Mratikul100k@) তৈরি করুন।

৩. Firestore Database তৈরি ও Security Rules

• Build > Firestore Database-এ গিয়ে Create database ক্লিক করুন।
• Rules ট্যাবে গিয়ে নিচের রুলসটি পেস্ট করুন:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Helper function to check if user is admin function isAdmin() { return request.auth != null && ( request.auth.token.email == "30atikul@gmail.com" ); } // Posts: Anyone can read published posts. Only admin can write. match /posts/{postId} { allow read: if resource.data.status == 'published' || isAdmin(); allow write: if isAdmin(); } // Categories: Anyone can read. Only admin can write. match /categories/{catId} { allow read: true; allow write: if isAdmin(); } // User Likes match /userLikes/{likeId} { allow read, write: if request.auth != null && request.auth.uid == resource.data.userId; allow create: if request.auth != null && request.auth.uid == request.resource.data.userId; } // User Saved Posts match /userSavedPosts/{saveId} { allow read, write: if request.auth != null && request.auth.uid == resource.data.userId; allow create: if request.auth != null && request.auth.uid == request.resource.data.userId; } } }

৪. Firebase Storage সক্রিয় করুন

• Build > Storage-এ গিয়ে Get started ক্লিক করুন।
• স্ট্যাটাস ছবির জন্য Rules ট্যাবে allow read: true; allow write: if request.auth != null; দিয়ে Publish করুন।
